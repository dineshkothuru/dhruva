# Trigger framework

- Every trigger delegates to `TriggerDispatcher`.
- Handler classes end in `TriggerHandler` and declare
  `with sharing` or a justified exception.
- Recursion guards live in `TriggerContext`, never
  static booleans in handlers.
- ⚠ `LegacySyncTriggerHandler` is vendor-managed —
  never modify, raise a ticket with the vendor.
⚠ Save-time checks: the no-secrets scan runs on every skill (a pasted API key is rejected); skills over the size cap show a truncation warning here.
